# Mangalam HDPE — Industrial Product Website

A modern and responsive industrial product website built using **HTML5, CSS3, and Vanilla JavaScript**, focused on clean UI implementation, responsive layouts, scalable frontend architecture, and interactive user experiences.

This project showcases a professional industrial landing page implementation with emphasis on responsive frontend development, modern UI practices, semantic structure, and smooth user interactions.

---

## Features

- Fully responsive design for desktop, tablet, and mobile devices
- Sticky navigation header on scroll
- Interactive hero image carousel
- Responsive applications showcase slider
- FAQ accordion functionality
- Responsive manufacturing process stepper
- Animated testimonial carousel
- Portfolio showcase section
- Smooth UI animations and transitions
- Semantic and accessible HTML structure
- Organized and maintainable CSS architecture
- Vanilla JavaScript interactions
- Cross-browser compatible layout

---
